# Referencias de placas Caravel

Carpeta con imágenes, plano de fabricación, dibujo de la tarjeta M.2/QFN y planilla de materiales descargados del Drive original. Son recursos **de la placa de desarrollo** y no asignaciones de pads o pines específicas de `miniaca` o `tffchain`.

El repositorio del proyecto de placa es [chipfoundry/caravel_board](https://github.com/chipfoundry/caravel_board). Para el archivo `caravel_board-main.zip` de aproximadamente 91 MB, usar ese repositorio o la [carpeta compartida de Drive](https://drive.google.com/drive/folders/1gQ6yE9ZW2dxFafuSmnaarN-BUkWn-Ljd), en lugar de duplicarlo en este repositorio.

**Pendiente para prueba en hardware:** solicitar la correspondencia completa entre los puertos RTL y los pads/pines del chip entregado (tags `c2p9` y `c2p10`), niveles eléctricos, tensiones de alimentación y método de conexión. El diagrama/layout de un circuito por sí solo no determina la numeración física de un encapsulado.
